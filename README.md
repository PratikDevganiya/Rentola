# Real Estate Marketplace (MERN Stack)

A modern real estate marketplace built using the MERN stack (MongoDB, Express.js, React, Node.js).
It allows users to browse, search, and manage property listings with secure authentication (JWT, Google OAuth) and state management using Redux Toolkit.

## Features
- Secure user authentication (JWT, Google OAuth)
- Create, read, update, and delete property listings
- Advanced search functionality with filters
- Image uploads for property listings

## Tech Stack
- **Frontend:** React, Redux Toolkit
- **Backend:** Node.js, Express.js
- **Database:** MongoDB

## Installation
1. Clone the repository
2. Install dependencies using `npm install`
3. Start the development server with `npm start`
